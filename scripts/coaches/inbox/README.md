# Boîte de dépôt des résumés de recherche

Dépose ici des fichiers `wave4-*.json` (même format que les faits de `src/core/coaches/data/facts.json` : topic, fact_fr, principle_fr, how_to_read_live_fr, author, title, url, read, caveat_fr, confidence).
Ils sont fusionnés par `python3 scripts/coaches/build-knowledge.py <dossier_recherche>`.
Ne dépose JAMAIS de transcriptions brutes (droits d'auteur) : seulement des résumés reformulés avec la source.
